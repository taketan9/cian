cian-gui 実機チェックリスト  v2.0.0
===================================

2.0.0 です。1.1.x からの積み上げ ── AI に事実を渡すようにしたこと、リモートが
実際に動くようになったこと、そして**「成功したと言いながら別の場所に書いていた」
不具合が4件**見つかって直ったことが中身です。

  第一部  黙って違う場所に書いていた4件   9 項目 （8 分・ここが本題）
  第二部  リモート（SFTP）              12 項目 （15 分・要サーバ）
  第三部  AI                            7 項目 （8 分）
  第四部  エディタと取り消し             9 項目 （7 分）
  第五部  顔と設定                       5 項目 （4 分）
  第六部  エディタの見た目と入口          6 項目 （5 分）
  第七部  共有マシンへの配布              5 項目 （10 分・AVD に置くとき）

落ちたときは番号と、画面に出た文字をそのまま送ってください。**「効かない」の
前に `:version` を撮ってください** ── どのビルドの話かが分からないと、直した
ものを直っていないと言われたのか、別のビルドを見ているのかが区別できません。


0. まず版を確かめる
-------------------

  [ ] 「:」→ version が **2.0.0** と今日のビルド日時を出す


第一部 ── 黙って違う場所に書いていた4件
=======================================

どれも「操作は成功した」と言いながら、**別の場所に書いて**いました。画面に
何も出ないのが共通点です。ここが今回いちばん確かめてほしいところです。

1. 開いている zip の中へコピー
------------------------------

  それまで: zip の**隣**にファイルが落ちて「コピーしました」と出ていた。

  [ ] 適当なフォルダを zip にする（メニュー → 圧縮）
  [ ] 片方のペインでその zip に Enter で入る
  [ ] 反対のペインでファイルを1つ選び、`c`
  [ ] 確認シートに「N 件を <zip名> に追加」と**zip の名前**が出る
  [ ] Enter → zip の一覧にそのファイルが現れる
  [ ] zip の**隣**（元のフォルダ）には増えていない

2. `c` でリモートへ（第二部に繋がる）
------------------------------------

  それまで: リモートペインに向けた `c` が**手元に**コピーしていた。

  [ ] 第二部の 6 番で確かめます

3. リモートペインで AI の走査
-----------------------------

  それまで: 手元のディスクを歩いて「これがサーバの中身です」と答えていた。

  [ ] リモートペインで `:aijunk` → **「リモートペインでは使えません」と断る**

4. コピーの取り消し
-------------------

  [ ] ファイルを1つ `c` で反対のペインへコピー
  [ ] `Ctrl+z`（または `u`）
  [ ] 「N 件のコピーを取り消しました（ゴミ箱へ）」と出て、コピー先から消える
  [ ] **同じ名前が既にあった場合は取り消しの対象にならない**（上書き・スキップ
      したものは、そのコピーが作ったものではないので触りません）


第二部 ── リモート（SFTP）
==========================

**ここは手元で本物のサーバ相手に通してあります**（自分で sshd を立てました）。
会社のサーバで同じことが起きるかを見てください。`init.lua` に `cian.ssh{…}` の
設定が要ります。

5. 鍵で入る（**新しい**）
-------------------------

  それまで: パスワードしか使えませんでした。設定例は前から鍵を勧めていたのに。

    cian.ssh { hosts = { { name = "srv", host = "10.0.0.1",
      users = { { name = "deploy", key = "~/.ssh/id_ed25519" } } } } }

  [ ] `:sftp` → そのホスト → **パスワードを訊かれずに**一覧が出る
  [ ] 鍵にパスフレーズがあるなら `key_pass` を足して同じことを確かめる

6. ローカル ↔ サーバ
--------------------

  [ ] 手元のペインでファイルを選び、リモートペインに向けて `c`
  [ ] 確認シートが **サーバ名:パス** を出す（手元のフォルダ名ではなく）
  [ ] 進捗バーが「アップロード」と出て、サーバ側に現れる
  [ ] 逆向き（リモートで `c`）でも降りてくる

7. ディレクトリごと（**新しい**）
--------------------------------

  それまで: フォルダは送れず、断っていました。

  [ ] 中に階層のあるフォルダを選んで `c`
  [ ] バーの分母が**ファイル数**（フォルダ数ではなく）
  [ ] サーバ側に深いところまで揃っている
  [ ] 逆向きでも同じ

8. サーバの中の操作
-------------------

  [ ] `A`（フォルダ作成）・`a`（ファイル作成）・`r`（改名）が効く
  [ ] `d` で**中身の入ったフォルダ**が消える
  [ ] `:chmod 600` が効く（`ls -l` で確かめてください）

9. サーバ → サーバ
------------------

  [ ] 両ペインを別のサーバに繋いで `c` → 「このパソコンを経由して」運ばれる
  [ ] **同じサーバの別ディレクトリ**へ `m` → 一瞬で終わる（rename なので）

10. 転送の速さの上限
--------------------

  [ ] `:limit 500k` → 大きめのファイルを送ると明らかに遅くなる
  [ ] `:limit off` で戻る


第三部 ── AI
============

**渡している事実を増やしました。**モデルを変えたわけではありません。

11. ゴミ検索
------------

  それまで: 1階層だけ、しかもフォルダのサイズが空欄でした。

  [ ] ビルド成果物のあるフォルダ（`target`・`node_modules` のある所）で `:aijunk`
  [ ] **大きいものが上に来る**（空けられる容量の順）
  [ ] 入れ子の内側（`target/debug` など）を重ねて挙げてこない
  [ ] 深いところにある `node_modules` も見つける

12. 打ち切りを言う
------------------

  [ ] とても大きなフォルダで `:aijunk` → 「N 階層下までで打ち切りました」が出る
      （何も出ないのに「ゴミはありません」と言われないこと）

13. コマンド提案
----------------

  それまで: OS しか渡しておらず、PowerShell と cmd を取り違えていました。

  [ ] `:aicmd この中の .log を消して` → **PowerShell の文法**で返る
  [ ] シェルパネルで `ssh` して Linux サーバに入ってから同じことを訊く
      → **その Linux 向けの**コマンドが返る（`ssh` で包まない）
  [ ] `init.lua` の `notes` にそのサーバのOSを書いてあれば、それに沿った答えになる
  [ ] 1行で書けない依頼（例: 「バックアップを取ってから消して」）
      → `# ` で始まる1行で**断る**


第四部 ── エディタと取り消し
============================

14. `jj` で挿入モードを抜ける（**新しい**）
------------------------------------------

  [ ] エディタで `i` → `jj` → ノーマルモードに戻り、**j は残らない**
  [ ] **日本語入力オンで** `j` を2回 → 同じく抜ける（`ｊｊ` / `っｊ`）

15. `ZZ` / `ZQ`（**新しい**）
-----------------------------

  [ ] ノーマルモードで `ZZ` → 保存して閉じる
  [ ] 何か直してから `ZQ` → 保存せずに閉じる

16. 行の操作が「notepad」でも届く（**新しい**）
---------------------------------------------

  それまで: `:sort` などは vim のコマンド行からしか使えず、notepad のキー操作では
  **どこからも届きませんでした**。

  [ ] `T` のメニューでエディタのキー操作を「notepad」にする
  [ ] エディタで **Shift+Enter** → 「行の操作 ▸」がある
  [ ] ソート・重複を落とす・全角→半角・改行コード が効く

17. Markdown のリンク（**新しい**）
----------------------------------

  それまで: 「相対リンクはまだ開けません」と言うだけでした。

  [ ] `.md` を開いて Ctrl+E でプレビュー
  [ ] 隣のファイルへのリンク（`./なにか.md`）を押す → そのファイルが開く
  [ ] 同じ文書内の見出しリンク（`#見出し`）を押す → そこまでスクロールする


第五部 ── 顔と設定
==================

18. アイコン（**新しい**）
-------------------------

  [ ] エクスプローラで `cian-server.exe` に **cian のアイコン**が付いている
      （前は Windows の既定アイコンでした）

19. シェルの設定が効く（**新しい**）
-----------------------------------

  それまで: ウィンドウ版は `cian.set_option("shell", …)` を**黙って無視**していました。

  [ ] `init.lua` に `cian.set_option("shell", "cmd.exe")` を書く
  [ ] cian を開き直してシェルパネル → cmd が出る（PowerShell ではなく）
  [ ] 書き戻して PowerShell に戻ることも確かめる

20. Windows が拒否したとき（**新しい**・試せれば）
-------------------------------------------------

  それまで: 「アクセスが拒否されました」で終わっていました。

  [ ] `C:\Program Files\` の下など、権限の要る場所へ `c`
  [ ] **「管理者としてやり直しますか」と訊いてくる**
  [ ] はい → UAC が出て、コピーが通る


おわりに
========

第一部の4件は、どれも**画面に出ないまま違う場所に書いていた**ものです。
似たものが他にもあるはずだと思っています ── 「成功したと言われたのに、
そこに無い」に気づいたら、それがどんなに小さくても教えてください。


第六部 ── エディタの見た目と入口
================================

21. 直した行が脇に出る（**新しい**）
------------------------------------

  それまで: 「汚れている」がファイル1つに1ビットしかなく、**どこを直したかは
  覚えているしかありませんでした。**

  [ ] ファイルを開いて1行足す → 行番号の**脇に棒**が出る
  [ ] もう1行、別の場所を直す → そこにも出る
  [ ] Ctrl+S で保存 → **棒が消える**（ファイルがディスクと同じになったので）
  [ ] 元に戻す（u / Ctrl+z）→ 棒が消える

22. 探す窓の表題（**新しい**）
-----------------------------

  それまで: `:find` と `:grep` としか出ず、どちらが何をするか分かりませんでした。

  [ ] Shift+F → 表題が **「名前で探す（この下すべて）」**
  [ ] Ctrl+F  → 表題が **「ファイルの中を探す（この下すべて）」**
  [ ] どちらも欄の中に何を打つかが薄く出て、下に `:find` / `:grep` が小さく出る

23. `z` の入力欄の幅（**新しい**）
---------------------------------

  [ ] `z` → 長いパスを打っても**見切れない**（欄が窓の幅に近い）

24. notepad のキー操作でも行の操作に届く（**新しい**）
-------------------------------------------

  それまで: `:sort` などは vim のコマンド行からしか使えませんでした。

  [ ] `T` のメニューでエディタのキー操作を「notepad」に
  [ ] エディタで **Shift+Enter** → 「行の操作 ▸」
  [ ] ソート・重複を落とす・全角→半角・改行コード が効く


第七部 ── 共有マシンへの配布（AVD に置くとき）
==============================================

同梱の `DEPLOY.ja.txt` の手順どおりに置いてから確かめてください。

25. 初回に設定が配られる
------------------------

  [ ] `gui\default-config\` に init.lua / ssh.lua を置く
  [ ] **設定を持っていない**アカウントで run.bat から起動
  [ ] `~/.config/cian/` にそれらが出来ている
  [ ] cian の中で `:where` → 読んでいるのが**そちら**だと出る

26. 二度目は上書きしない
------------------------

  [ ] その人の `ssh.lua` に1台足す
  [ ] cian を開き直す → **足したものが残っている**

27. 罠を踏んでいないこと
------------------------

  [ ] `gui\` の**直下に** init.lua / shortcuts.lua / macro.lua が**無い**
  [ ] `:where` の「書くとしたら」が `~/.config/cian` を指している
      （`C:\Program Files\...` を指していたら、しおりが保存できません）
  [ ] しおりを1つ足して cian を開き直す → 残っている
