cian — 窓版（Electron） Windows x64
===================================

端末版の cian をそのまま窓に移したものです。中身は JavaScript なので、
コンパイラも Rust も要りません。要るのは Electron 本体だけです。

同梱しているもの
  main.js / renderer.js / index.html   前面（窓の中身そのもの）
  vendor\                              エディタの実行時一式
                                       （Monaco・monaco-vim・mermaid・同梱フォント）
  cian-server.exe                      エンジン。前面はこれと話します
  run.bat                              Electron を探して起動する
  examples\init.lua                    設定の見本

同梱していないもの
  Electron 本体。247MB あり、社内にすでにあるものを使う前提です。
  無ければ https://github.com/electron/electron/releases から
  electron-v33.x.x-win32-x64.zip を落として展開してください。

起動
  1. zip を右クリック →「プロパティ」→ 下のほうに「セキュリティ: このファイルは
     他のコンピューターから取得したものです」があれば「許可する」にチェック → OK。
     ここで外しておかないと、展開後の全ファイルに印が付いたままになり、
     cian-server.exe が黙って起動しないことがあります。展開してから1つずつ
     外すより、zip のうちに1回外すほうが早いです。
  2. 右クリック →「すべて展開」で好きな場所に出す
  3. Electron の場所を教える（下記）
  4. run.bat をダブルクリック

黒いコマンドプロンプトが一瞬出るのを止めたい
  run.bat はバッチファイルなので、**cmd.exe が1行目を読む前にコンソールの窓を
  作ります**。中身を速くしても消えません（run.bat は最後の1行で `start` して
  すぐ終わるので、既にいちばん短い形です）。

  止めるなら、run.bat を通らない道を1本作ります。**electron.exe への
  ショートカット**です。Electron 本体は窓のアプリなので、コンソールを一度も
  持ちません。

    1. デスクトップで右クリック →「新規作成」→「ショートカット」
    2. 場所に、Electron と cian のフォルダをこの順で書く（両方とも引用符つき）

         "D:\apps\electron-v33.4.11-win32-x64\electron.exe" "C:\cian\cian-gui-win-x64"

    3. 名前を cian にして完了。アイコンを変えたければ、プロパティ →
       「アイコンの変更」で同じフォルダの cian.ico を指す

  **run.bat がやっていたことは飛びます。** Electron を探す・共有マシンで
  default-config を配る・「exe の隣に init.lua がある」と警告する・
  cian-server.exe が無いと言う ── 一度うまく起動した機械では全部済んでいる
  話なので、そこから先はショートカットで構いません。**初回は run.bat で
  起動して**、通ったらショートカットを作るのが安全です。

管理者として起動したい
  上のショートカットのプロパティ →「ショートカット」タブ →「詳細設定」→
  **「管理者として実行」** にチェック。run.bat へのショートカットでも同じ
  ところにあります（黒い窓は出ますが、管理者にはなります）。

  ★ 先に知っておいてほしいこと

    ・**起動のたびに UAC の確認が出ます。** 出ないようにする設定はありません
    ・**エクスプローラとのドラッグ＆ドロップが効かなくなります。** Windows は
      権限の高い窓へ低いほうから物を渡させません（UIPI）。デスクトップへの
      ドラッグ出しも同じ理由で止まります
    ・**シェルパネルが管理者のシェルになります。** そこで打つものは全部
      管理者権限で走る、ということです
    ・設定の場所は変わりません（同じユーザなので %USERPROFILE% は同じ）

  **コピーだけが目的なら、管理者で起動する必要はありません。** Program Files
  などへの書き込みが「アクセスが拒否されました」で止まったとき、cian は
  その場で「管理者で実行し直しますか」と訊きます（エクスプローラの
  「管理者のアクセス許可が必要です」と同じ形）。効く範囲がその1回のコピー
  だけなので、ドラッグもシェルも巻き込みません。

Electron の場所の教え方
  Electron を別の場所に置いている場合は、展開したフォルダに electron.txt を
  作って1行だけ書いてください。メモ帳で作れます。

       D:\apps\electron-v33.4.11-win32-x64

  electron.exe まで書いても、それが入っているフォルダまででも受けます。
  引用符も末尾の \ も要りません。; で始まる行は覚え書きとして読み飛ばします。

  ★ run.bat を直接書き換えないでください。動きはしますが、次の版を展開した
    ときに上書きされて、毎回やり直しになります。electron.txt は配布物に
    入れていないので上書きされません。

  一時的に別の Electron で試したいときは環境変数が最優先です:
       set CIAN_ELECTRON=D:\apps\electron-v33.4.11-win32-x64\electron.exe

  探す順は CIAN_ELECTRON → electron.txt → 隣の electron-v* → 1つ上 →
  2つ上 → node_modules。見つからなければ探した場所を全部言って止まります
  （黙って落ちるのが一番たちが悪いので）。

  Electron をこの zip の展開先の中か隣に置くなら、electron.txt すら要りません:
       C:\tools\cian\               ← この zip の中身
       C:\tools\cian\electron-v33.4.11-win32-x64\electron.exe

動いているものを確かめる
  窓の中で「:」を打って version と入れると、いま動いている版とビルド日時が
  出ます。直したはずのものが直っていないときは、まずこれを見てください。
  古い exe を掴んでいるだけ、というのが一番多い落とし穴です。

実機で見てほしいこと
  CHECK.ja.txt を同梱しています。この版で入ったものと、
  **こちらで一度も動かせていないもの**（SFTP まわり）が分けて書いてあります。
  上から順に 20 分ほどで一周できます。

設定
  %USERPROFILE%\.config\cian\init.lua を端末版と共用します。同じファイルが
  そのまま効きます（CIAN_CONFIG_DIR で置き場所を変えられます）。
  読む項目は端末版と同じではありません — 窓版が見ているものは
  gui\ROADMAP.ja.md に一覧があります。

フォント
  vendor\fonts\cian.ttf（HackGen Console NF）を同梱していて、窓が自分で
  読み込みます。インストールは不要です。これが無いと一覧が等幅にならず、
  アイコンが豆腐になります。

うまくいかないとき
  窓は出るが中身が空
    cian-server.exe がこのフォルダにあるか確認してください。前面は
    「隣の cian-server.exe」を最優先で探します。
  文字が化ける・アイコンが四角
    vendor\fonts\cian.ttf があるか確認してください。
  Ctrl のキーが効かない
    既定のメニューが Ctrl+W などを持っていく問題は前面側で外してあります。
    それでも効かないものがあれば、どのキーかを控えてください。
  何も起きない・一瞬で閉じる
    ブロックが外れていない可能性があります。展開したフォルダの
    cian-server.exe を右クリック →「プロパティ」→「許可する」。
    PowerShell が使えるなら、フォルダごと一度に外せます:
        Get-ChildItem -Recurse | Unblock-File

エンジンだけ新しくしたいとき
  リリースの cian-server-win-x64.exe を落として、このフォルダの
  cian-server.exe に名前を変えて上書きしてください。前面は隣のこれを
  最優先で使います。前面（JavaScript）は変わらないので、エンジンの
  修正だけならこれが一番小さい持ち込みです（9MB）。
