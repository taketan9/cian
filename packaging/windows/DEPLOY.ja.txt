cian-gui を全員に配る（AVD / 共有マシン）
=========================================

Program Files に置いて、共通デスクトップの run.bat から全員が起動する ──
という配り方の手順です。**インストーラは要りません。**

なぜ要らないか、は最後に書きます。先に、**これだけは踏まないでほしい罠**から。


踏んではいけない罠
==================

**exe の隣に init.lua を置かないでください。**

cian の設定は「持ち歩ける」ことを優先していて、**exe の隣にある設定が
~/.config/cian より優先されます ── 読みだけでなく、書きも**です。

つまり Program Files の cian-gui フォルダに init.lua を1つ置くと:

  ・全員がそれを読む                       ← 配りたかったこと
  ・**しおり（shortcuts.lua）の保存先も** そこになる
  ・Program Files は一般ユーザが書けない   ← 全員のしおりが保存できない

配りたかったものの代わりに、壊したくなかったものが壊れます。しかも静かに。

判定は `crates/cian-lua/src/lib.rs` の `config_write_path` です。exe の隣に
`init.lua` / `shortcuts.lua` / `macro.lua` のどれかがあると、書き込み先が
そちらに切り替わります。

**確かめ方**: cian の中で `:where` を叩くと、いま読んでいるファイルと、
書くとしたらどこかを両方出します。配布後に一度これを見てください。


置きかた
========

  C:\Program Files\cian\
      electron\                      ← Electron を展開したもの
      gui\                           ← cian-gui-win-x64.zip を展開したもの
          run.bat
          cian-server.exe
          electron.txt               ← 1行だけ: C:\Program Files\cian\electron
          default-config\            ← ここが配布したい設定
              init.lua               ← 無い人にだけ配る（あとは本人のもの）
              keymap.lua             ←    〃
              ssh.lua                ←    〃

  C:\Users\Public\Desktop\cian.lnk   ← gui\run.bat へのショートカット

**Electron 同梱版（cian-win-x64.zip）を配るときは、もっと短くなります。**

  C:\Program Files\cian\
      cian.exe                       ← 共通デスクトップのショートカットはこれ
      resources\app\                cian 本体
      default-config\                ← 同じ。初回だけ配られる
          init.lua  keymap.lua  ssh.lua

Electron を置く場所も `electron.txt` も要りません。**初回に配る仕事は
`run.bat` ではなく cian 自身（`gui/main.js` の `seedConfig`）がやります** ──
`cian.exe` を直に叩くと run.bat を通らないので、入口ごとに書くのをやめて
中に1つ置きました。どちらの配り方でも、配られるものと規則は同じです。

規則は**1つだけ**です:

  **その人がまだ持っていないファイルだけを配る。**
  一度配ったら、それはその人のもの。次の起動で上書きしません。

ssh.lua も同じです。**使っている人の設定ファイルを、使っている最中に書き換え
ない** ── サーバの一覧を渡されて最初にやることは、たいてい「足りない1台を
足す」ことで、それが次の起動で消える道具は信用できません。

  init.lua      表示・AI・git など          → 初回だけ配る
  keymap.lua    キー割り当て                → 初回だけ配る
  ssh.lua       接続先のサーバ              → 初回だけ配る
  shortcuts.lua しおり                      → **配らない**（本人のもの）
  macro.lua     マクロ                      → 配ってもよい


パスワードについて
==================

`ssh.lua` に平文の `password` を書いて全員に配ると、**全員がそれを読めます。**
共有マシンでは特に。次のどちらかにしてください:

  ・`key = "~/.ssh/id_ed25519"`  … 鍵で入る（1.2.0 から使えます）
  ・`password_cmd = "..."`        … その標準出力を使うので、秘密は
                                    Windows の資格情報マネージャに置けます

cian は、パスワードを含む設定ファイルが誰でも読める権限だと起動時に警告します。


更新のしかた
============

  ・cian を上げる      … `gui\` を新しい zip の中身で置き換える
                         （`electron.txt` と `default-config\` は zip に
                          入っていないので残ります）
  ・`default-config\` を直す
                       … **これから初めて使う人にだけ**届きます。
                          すでに使っている人のファイルはその人のものなので、
                          触りません

**すでに配った設定を、あとから全員に押し込む道はありません。** 意図してそう
してあります（上の規則の裏返しです）。新しいサーバを全員に行き渡らせたいなら、
やり方は2つ:

  ・その1行を配る    … 「ssh.lua にこれを足してください」と伝える。
                       一番静かで、相手の設定を壊しません
  ・配り直させる      … 「`~/.config/cian\ssh.lua` を消して起動し直して」と
                       伝える。**その人が足した分も消えます**ので、
                       そう言ってから


インストーラを作るべきか
========================

**いまは要らない**と考えています。理由:

  ・欲しいのは「Program Files に置く」「デスクトップにショートカット」
    「初回に設定を配る」の3つで、上の手順が3つとも満たします
  ・バッチは中身が読めて、戻せます。何が起きるか、動かす前に分かる
  ・社内の管理された Windows では、インストーラは署名と、更新のたびの
    管理者権限がついて回ります

作る価値が出るのは、次のどれかが必要になったときです:

  ・ユーザごとのアンインストール
  ・スタートメニューへの登録、拡張子の関連付け
  ・自動更新
